## 🔍 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on Diwali sales data to help businesses understand:

- 👥 Customer demographics  
- 💸 Purchasing behavior  
- 📦 Product category trends  
- 🌎 Regional sales distribution

The goal? **Smarter marketing, better product placement, and festive-season profit maximization!**

---

## 📊 Key Insights

Here’s what the data reveals:

- 🧑‍🤝‍🧑 **Gender-based Trends**: One gender *clearly* dominates the Diwali spending charts.
- 💼 **Top Professions**: Certain occupations spend significantly more — targeting them = more ROI.
- 🛍️ **Hot-Selling Categories**: Some product categories consistently outperform others.
- 🗺️ **State-wise Revenue**: Specific states generate massive festive sales (hello Maharashtra 👋).
- 🎂 **Age Groups**: Young adults seem to spend big during Diwali.
