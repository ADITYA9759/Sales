# Diwali Sales Analysis

This project analyzes Diwali sales data to uncover insights related to customer demographics, purchasing behavior, and regional sales performance. The analysis is performed using Python libraries such as Pandas, Matplotlib, and Seaborn.

Project Overview

The goal of this project is to perform an exploratory data analysis (EDA) on Diwali sales data to help businesses understand:

Customer demographics

Purchasing behavior

Product category trends

Regional sales distribution


By analyzing the dataset, businesses can make informed decisions to optimize marketing strategies, product placement, and customer targeting during the festive season.

Key Insights

Which gender contributes more to overall sales.

Which product categories and occupations drive the highest sales.

States generating the maximum revenue during Diwali.

Age groups that spend the most during Diwali sales.
